# 護衛のリズム

王女を護衛し、巨大ゴーレムの固定攻撃パターンを盾で防ぐ、スマホ向けGodot 4プロトタイプです。

## 現在の試作範囲

- 長押しで盾を構え、岩の衝撃を防ぐ
- 腕力と戦闘中に減る最大腕力
- 帰還魔法、素材、睡眠による超回復
- 端末内セーブデータ
- 1体の巨大ゴーレムとの戦闘

## 検討中の戦闘仕様：盾の護衛共鳴（未実装）

盾を**構え切ったまま一定時間維持**すると、王女の魔法を補助する「護衛共鳴」が発動する案。
短い反射的な防御だけでなく、スタミナを使って防御姿勢を維持する判断を作ることが目的。

- 被弾しても共鳴は解除されない。条件は「盾を下ろさず構え続ける」ことだけ。
- 盾を下ろした時点で共鳴は切れる。被弾で最大腕力が削られるため、強い攻撃を受けながら維持するほど苦しくなる。
- 共鳴中、王女の次の詠唱・攻撃に盾固有の補助効果が乗る。
- 効果の数値、発動までの時間、保持できる回数はプレイ検証で決める。仮の検証値は「3秒維持で次の王女攻撃を1.8倍」。

盾は単なる上位互換ではなく、共鳴効果でも使い分ける想定。

| 盾の系統案 | 共鳴効果案 | 主な用途 |
| --- | --- | --- |
| 鉄壁盾 | 王女の攻撃力を上げる | 強い一撃・深い採掘 |
| 採掘盾 | 素材獲得量を上げる | 素材集め |
| 月光盾 | 王女の詠唱時間を短縮する | 攻撃回転率 |
| 守護盾 | 被弾時の最大腕力減少を軽減する | 長期戦 |
| 反響盾 | 防御成功ごとに共鳴の発動を早める | 防御を続ける戦い |

> この節は企画メモであり、まだゲームには実装しない。
